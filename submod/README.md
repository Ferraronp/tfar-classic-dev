# TFAR Classic Fixes 1.0.0

Отдельный сабмод для **оригинального TFAR Classic 0.9.12**. Исправляет позицию
голоса Zeus при remote control и связанные с переключением юнита рации.

Оригинальный task_force_radio.pbo заменять не нужно. Сабмод не содержит моделей,
звуков, текстур, task_force_radio_pipe.dll или TeamSpeak-плагина TFAR.

## Что меняется

- При управлении бойцом голос исходит от бойца и слышен с обычной дистанцией TFAR.
- Собеседники рядом с бойцом обрабатывают его позицию даже при удалённом теле Zeus.
- Переход A → B, выход из управления, смерть/удаление бойца обновляют источник.
- Зажатая передача завершается при смене юнита.
- SW/LR берутся из инвентаря управляемого бойца; рации тела Zeus не подмешиваются.
- Скопированные SW-рации получают отдельные экземпляры при нормализации инвентаря.

Это прежняя модель радио TFAR: частоты, side codes, PTT, DSP, громкость и дальность.
Open/Keyed, NET codes и protocol-v2 routing в сабмоде отсутствуют.

## Зависимости и установка

1. Установить **CBA_A3** и **оригинальный TFAR Classic 0.9.12**.
2. Если раньше ставился наш полный изменённый task_force_radio.pbo, восстановить
   оригинальный мод из резервной копии/официальной поставки. Не совмещать оба фикса:
   изменённый полный PBO уже содержит собственный обработчик смены юнита.
3. Распаковать tfar-classic-fixes.zip в отдельную папку. Получится
   @tfar_classic_fixes/addons/tfar_classic_fixes.pbo и его подпись.
4. Добавить @tfar_classic_fixes как локальный мод в Arma Launcher. Включить
   **CBA_A3 + TFAR Classic + TFAR Classic Fixes** у **всех клиентов**, включая Zeus
   и слушателей. Порядок загрузки PBO задаётся requiredAddons.
5. Для сервера с verifySignatures скопировать .bikey из
   @tfar_classic_fixes/keys в серверную папку keys. Сам сабмод можно также
   загрузить на сервере; голосовые исправления выполняются на клиентах.
6. Полностью перезапустить Arma после установки или обновления.

Сабмод рассчитан на Classic 0.9.12, а не TFAR 1.x/Beta, ACRE или другой форк.
В редакторе не требуется добавлять модуль или менять миссию.
Чтобы откатиться, отключить только @tfar_classic_fixes.

### TeamSpeak

Новый игровой сабмод не изменяет API плагинов TeamSpeak. Для TS3 3.6.x нужен
отдельный совместимый TFAR Classic plugin API 26. Если он уже установлен и
работает, повторная замена не нужна.

Проверенная сборка API 26:
https://github.com/Ferraronp/tfar-classic-dev/actions/runs/38784358939
(артефакты Actions временные). Историческая инструкция сборки TS-плагина остаётся
в BUILDING.md репозитория. TS6 этой поставкой не проверяется.

CI этого сабмода не собирает и не включает TS DLL или .ts3_plugin.

## Проверка в игре

Нужны два человека в multiplayer и в одном канале TeamSpeak. У обоих включён
сабмод. Тело Zeus разместить не менее чем в 500 м от тестовой группы. Рядом с
обычным игроком поставить двух AI-бойцов A и B. Говорить обычным голосом, не PTT
рации; проверить передачу в обе стороны.

| Действие | Ожидаемый результат |
| --- | --- |
| Zeus берёт A под контроль | Игрок рядом слышит Zeus из позиции A; Zeus слышит игрока оттуда же |
| A отходит за обычную дальность голоса | Голос ослабевает/пропадает по обычным правилам TFAR |
| Zeus переключается A → B | Источник и точка прослушивания переходят к B |
| Zeus выходит из remote control | Нет оставшегося голоса из позиции A/B; возвращается обычное поведение Zeus |
| Управляемый AI погибает или удаляется | Нет привязки к мёртвому/удалённому AI; состояние возвращается к player |
| Переключение во время зажатого SW/LR PTT | Передача завершается, на следующем юните PTT работает |
| У AI другие SW/LR и частоты | Используются рации AI, без примеси раций исходного тела Zeus |
| AI получил копию loadout игрока | После выдачи отдельного SW-экземпляра изменение его частоты не меняет рацию тела Zeus |
| Игрок заходит после начала миссии | Remote-controlled Zeus слышен и поздно подключившемуся клиенту |
| Обычные игроки без Zeus | Локальный голос, SW/LR, additional channel и speakers работают как прежде |

Дождаться завершения сообщения о выдаче раций перед проверкой их настроек.
В транспорте проверить водитель/пассажир/turned-out отдельно: это не исправление
всех известных проблем изоляции транспорта Classic.

Для диагностики в LOCAL EXEC:

~~~sqf
hint str [
    missionNamespace getVariable ["TFARCF_initialized", false],
    call TFAR_fnc_currentUnit,
    missionNamespace getVariable ["TFAR_currentUnit", objNull],
    player getVariable ["tf_controlled_unit", objNull]
];
~~~

Первое значение — true; при управлении живым бойцом остальные три указывают
на него. Без remote control второе/третье — player, четвёртое — objNull.
В RPT есть строка TFAR Classic Fixes 1.0.0 initialized.

## Сборка

Нужны Python 3.10+ и [HEMTT](https://hemtt.dev/installation/). Из корня репозитория:

~~~sh
python scripts/build-submod.py
~~~

Результат: dist/submod/tfar-classic-fixes.zip и SHA256SUMS.txt.
Проверка исходников без HEMTT: python scripts/build-submod.py --check-only.
Сборка использует только submod/; исходники полного TFAR, Git LFS, Arma 3 Tools
и установленные Arma/CBA/TFAR ей не нужны. Зависимости нужны при запуске игры.

В архиве один PBO с отдельным prefix tfar_classic_fixes, подпись, публичный ключ,
документы и BUILD.json с commit SHA. Скрипт проверяет содержимое PBO, совпадение
упакованных SQF с исходниками и подпись. Private key в архив не включается.
CI генерирует **тестовый ключ**, который может измениться между сборками:
обновлять серверный .bikey вместе с .bisign. Для постоянного публичного
релиза нужен отдельный контролируемый ключ.
